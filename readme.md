# Movie Search App

A MERN stack movie search application using React, Node.js, Express, and OMDb API.

## Features
- Search movies
- Responsive UI
- Movie posters
- Dark theme

## Tech Stack
- React
- Node.js
- Express
- Axios
- OMDb API

## Run Project

### Backend
cd server
npm install
npm start

### Frontend
cd client
npm install
npm start
